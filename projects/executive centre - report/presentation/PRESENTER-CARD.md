# Presenter Quick Reference

> Print this or keep it open on a second screen. It's a skeleton — not a script.

---

## Timing

| Section | Time | First words |
|---------|------|-------------|
| 1 · The Before | 4 min | *"Before I show you what we've built..."* |
| 2 · Reports + Agents | 15 min | *"So that's the before. Here's what we built instead."* |
| 3 · The Engine | 5 min | *"Let me show you what's running underneath all of this."* |
| 4 · How We Build It | 6 min | *"The reports are the visible part. Here's how we build and maintain it."* |
| 5 · What's Next | 6 min | *"The foundation is solid. Here's where this goes."* |

## Tech Checklist (Before You Start)

- [ ] Screen sharing / display confirmed working
- [ ] Service Agent tested — all sample questions return good results
- [ ] Parts & Invoice Agent tested — all sample questions return good results
- [ ] Reports confirmed refreshed and current
- [ ] Data flow diagram displays correctly at presentation resolution
- [ ] Backup: know which slide covers each section if demo fails

---

## If It Goes Long — Cut in This Order

1. Trim Section 4 (skip knowledge base and code-first bullets)
2. Show 3 reports instead of 4 in Section 2
3. Skip Parts Agent if Service Agent demo ran long

## If It Goes Short — Expand in This Order

1. Let Q&A start early — they'll have questions
2. Go deeper on one agent (more questions, explain what it's doing)
3. Expand on the rollout/security story in Section 5
