# 0.13.1 try-it: export several transfer orders at once (mock mode)

For Brian, before deploying 0.13.1. The **Transfer orders** tab gets an **Export (N)** button for the ticked
transfers: one CSV with every ticked transfer's lines, and each one is marked Exported, exactly as if you had
exported it from its own page.

**Start:** in PowerShell, `cd C:\Users\bfox\Documents\Git-Projects\nonjd-order-app`, then `npm run dev`, and open the
address it prints. Mock mode uses made-up data and never writes to SharePoint; a page refresh starts the mock over.

## 1. Make a second transfer to export

Open **Transfers**. The **Transfer orders** tab has one Draft, **92-1-20261021-0900** (92 → 1, one line). Go to
**Suggestions**, set **From** to **92** and **Save**: "Saved 1 transfer order." Back on **Transfer orders** there are
now two Drafts.

## 2. Export both at once

Tick the box in the heading (every transfer shown). **Export (2)** appears beside Archive. Press it: one file
downloads, `Transfer-orders-<today>.csv`, and the message reads "Exported 2 transfer orders (3 lines)." Both rows now
say **Exported** with an export count of 1. Open the CSV: the first three columns are **Transfer, From, To**, then
the usual PartNumber … LineValue; the new transfer's two lines come first (newest first), then the older one's.

*Look for:* whether the file is what you'd want to work from, and whether the message is clear.

## 3. What can't be exported

Turn on **Show archived**: a Cancelled, archived transfer appears (1-95-…). Tick it with one of the others: Export is
greyed out and says "Only Draft or Exported transfer orders that aren't archived can be exported." Tick it alone:
only **Unarchive** is offered. Filters work with tick-all: set **To** to one branch, tick the heading box, and Export
takes only what's shown.

**Then:** App Settings → About should say **Version 0.13.1**. In the real app the file and the Exported status work
the same way; if the sign-in has expired partway, the list shows which transfers were downloaded but not recorded,
with **Try again** (records them without downloading again).
