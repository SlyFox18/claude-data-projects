click freely. Everything resets when you reload the page.

**Start:** in PowerShell, `cd C:\Users\bfox\Documents\Git-Projects\nonjd-order-app`, then `npm run dev`, and open
the address it prints (usually http://localhost:5173). You're signed in as "Test User".
