# 0.11.0 try-it: Cleanup checks (mock mode)

For Brian, before deploying 0.11.0. Cleanup is now a list of checks: lists of parts to fix in Equip, over every
branch. Two are built in: **Minimums with no demand** (as before) and the new **Stock value with no quantity** (Ben's
"value without quantity": Equip shows a stock value of $1 or more, either way, but nothing or less than nothing on
hand). Anyone can build their own from conditions such as "On hand > 0" and "Sales 24 months = 0".

**Start:** in PowerShell, `cd C:\Users\bfox\Documents\Git-Projects\nonjd-order-app`, then `npm run dev`, and open the
address it prints. Mock mode uses made-up data and never writes to SharePoint; a page refresh starts the mock over.
The mock has a saved check **Old stock, no sales 2 years** (by "Ben Hill") and an archived "Zero-cost parts".

## 1. Find stock value with no quantity

Open **Cleanup** from the launch page (in the left menu it's **Checks**). The page lists the checks with how many parts each finds;
the counts fill in as the branches load. Open **Stock value with no quantity**. In the mock it finds two parts at
branch 1: **BS-VAL-NOQTY** (nothing on hand, $120.00 of value) and **BS-VAL-NEG** (−2 on hand, −$45.00). Try the
branch filter, click a column heading to sort, and **Export CSV**. Back on the list, **Minimums with no demand** opens
the same page as before.

*Look for:* whether the wording on the list and the results page makes sense to a parts manager.

## 2. Build your own check

Click **New check**. Name it, then set the first condition to **On hand** **>** **0**. **Add condition**: **Sales 24
months** **=** **0**. The **Try it** card shows how many parts match and the first 20, and updates as you change
the conditions. Try a date: **Last received** **before, or never** **24** **months ago** (parts never received count
as old). Click **Save check**: it opens its results with "Check saved.". **Edit** brings you back to change it; saving
again says "Check updated.". **← Cleanup checks** at the top takes you back to the list.

*Look for:* whether the field / comparison / value rows are easy to read, and anything you expected to find in the
field list that isn't there.

## 3. Tidy the list

On the Cleanup list, **Switch off** your check: it stays, marked **Off**. **Archive** it: it leaves the list;
**Show archived** brings it back with **Unarchive**.

**Then:** App Settings → **About** should say **Version 0.11.0**. In the real app, until the new publish runs, the
Stock value check says "Equip stock value isn't in today's data yet"; that's expected for the first morning.
