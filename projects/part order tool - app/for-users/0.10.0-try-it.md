# 0.10.0 try-it: One-Time templates (mock mode)

For Brian, before deploying 0.10.0. A template saves a One-Time Order's Set up (branches, franchises, dealer groups,
the months, the calculation and line limits) under a name, so a season's order is one click to start. Everyone shares
the same templates, anyone can change them, and each change is recorded.

**Start:** in PowerShell, `cd C:\Users\bfox\Documents\Git-Projects\nonjd-order-app`, then `npm run dev`, and open the
address it prints. Mock mode uses made-up data and never writes to SharePoint; a page refresh starts the mock over.
The mock has one template, **Cotton pre-season** (branches 1 and 92, franchise BS, Rolling 12, factor 1.5), last
changed by "Shannon Cole", and an archived "Old 2024 order".

## 1. Start this season's order from a template

Open **Non-JD ordering → One-Time Order**. At the top of Set up there's a new **Template** card. Pick
**Cotton pre-season** and click **Use**. It ticks branches 1 and 92, waits for them to load, then fills in BS, the
last 12 months and loading factor 1.5, and names the order "Cotton pre-season" (only because the name was blank).
**History** shows who changed it and when (Ben created it, Shannon changed the factor). From here the order works as
before, and Review's line ends "· From template Cotton pre-season". (Once you've used a template, the card tells you
next time if someone else changed it since: "Changed by Shannon Cole on …". The mock can't show that on a first
visit.)

*Look for:* anything that didn't fill in, or wording on the card that doesn't make sense.

## 2. Change a template and see the history

With Cotton pre-season in use, change **Loading factor** to 2. **Update template** lights up, and a line under the
buttons says "Not saved to the template yet: loading factor 1.5 → 2". Click **Update template**: it says "Template
updated." Now open **Templates** in the left menu (right under One-Time Order): the
Cotton pre-season row reads "… · total units sold × 2", and its **History** has your change at the top. **Start order**
on that row takes you back to One-Time Order with the template filled in.

*Look for:* whether "Update template" vs "Save as new template" is clear, and whether the history reads well.

## 3. Save your own, then archive it

Start a fresh One-Time Order (reload the page), set it up any way you like, and click **Save as template**. Give it a
name and an optional description and **Save**. It's now in the Template list and on the Templates page. On the
Templates page click **Archive** on it and confirm: it disappears from the list (and from One-Time's template
picker). Turn on **Show archived** to see it again with **Unarchive**.

*Look for:* anything about saving or archiving that felt unexpected.
