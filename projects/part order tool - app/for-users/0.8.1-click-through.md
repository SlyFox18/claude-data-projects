# 0.8.1 click-through (mock mode)

For Brian, before deploying 0.8.1. Barry's ask: One-Time Order's **Loading factor**, **Total / Avg / mo**, **Min
demands** and **Min sales** are now set on **Set up**, before Transfers, so the Transfers step suggests against the
quantities the order really needs. Review shows them as one line with **Change in Set up**. Mock mode uses made-up
data and never writes to SharePoint.

**Start:** in PowerShell, `cd C:\Users\bfox\Documents\Git-Projects\nonjd-order-app`, then `npm run dev`, and open
the address it prints (usually http://localhost:5173).

**The mock part:** at branch 1, franchise BS, **BS-XFER-1** sold 24 in the last 12 months, has 0 on hand and 2
already coming, and branch 92 can spare 26 of it.

| # | Do | You should see |
|---|---|---|
| 1 | Open **Non-JD ordering → One-Time Order**. Name it **TEST**, keep branch **1**, tick franchise **BS**. | On Set up, a new **Calculation** card between Branches and franchises and Line value limits: **Loading factor** 1, **Calculate from** Total / Avg / mo, **Min demands** 0, **Min sales** 0, with a line explaining what it orders. The Order summary on the right has **Calculation: Rolling 12, total units sold × 1**. |
| 2 | Click **Continue to transfers** and wait for every branch to load. | BS-XFER-1: **22 from 92**, Order **22 → 0** (as in 0.8.0). |
| 3 | Click **Back to setup**. Set **Loading factor** to **1.5**. Click **Continue to transfers**. | The summary first reads "× 1.5". On Transfers, BS-XFER-1 is now **26 from 92**, Order **34 → 8**: 24 × 1.5 = 36, less the 2 coming, and 92 can only spare 26. |
| 4 | Click **Continue to review ›** and choose **Continue without them**. | Review starts with a line **Rolling 12, total units sold × 1.5** and the explanation, plus a **Change in Set up** button. There are no factor or minimum boxes on Review any more. BS-XFER-1 orders 34. |
| 5 | Click **Change in Set up**. Set **Min sales** to **30**, then **Continue to transfers**. | Straight to Review (nothing to transfer): BS-XFER-1 (24 sold) is no longer on the order, and its transfer isn't offered either. The summary line adds "min sales 30". |
| 6 | Click **Change in Set up**. Set **Loading factor** to **0**. | Under the summary: "Loading factor must be a number above 0." and **Continue to transfers** is greyed out. Set it back to 1. |
| 7 | Click **Avg / mo** on Set up. | The factor's label changes to **Months of supply**, and the explanation and summary say "1 month's worth of the monthly average units sold". |
| 8 | App Settings → **About**. | **Version 0.8.1** · commit … |
