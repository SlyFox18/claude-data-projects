# Ben's answers on transfers and phase-in (2026-10-27)

On 2026-10-27 Brian emailed Ben seven questions, each giving the default we planned to build. Below are Ben's replies, verbatim, and where each one lands in the round 2 spec's assumptions.

| # | Question (our default) | Ben | Spec |
|---|---|---|---|
| 1 | **Extra stock.** Anything above 12 months of supply is extra. Stock with no sales is all extra unless it has a minimum. Committed stock is never moved. | "This is correct. But this needs to be a field that we can change the rules for." | A2, A3 confirmed. The 12 months is already the transfer rule's ExcessSupply. |
| 2 | **Transfer before buying.** Minimums with no sales don't pull transfers. | "That is correct. But when we were working the transfer, if we decided not to transfer from another store, it would recalculate the order to the recommended order quantity." | A4, A5 confirmed. Unticking a transfer puts the order back to the full quantity (Part 4: the preview counts ticked transfers only). |
| 3 | **Order of filling.** The branch with the most extra sends first, and out-of-stock branches are filled first. Any branch-pair rules? | "Yes. The branch with the greatest months of supply sends first and with lowest months of supply receives first. Right now there do not need to be rules on specific locations sending to each other. This is still best done manually since there are so many different scenarios." | **A6 changed:** senders go by greatest months of supply, receivers by lowest months of supply. A7 confirmed: no branch-pair rules. |
| 4 | **Redistribution.** Up to 6 months of supply at the receiver; lines under $25 are skipped. | "6 months is good for now. There does not need to be a minimum dollar amount. This also needs to be a field that we can change the rules for." | A8 confirmed. **A9 changed:** the default minimum is $0. RedistMinValue stays a rule field. |
| 5 | **Saving.** One transfer per sending + receiving pair, all franchises together. CSV keyed into Equip. Conventional starts ticked, redistribution unticked. | "Yes, sending and receiving branch pairs need to be kept up with together. All Franchises can be shown together but with a filter at the top where they can be worked separately if we choose to. These will have to be exported and manually keyed into Equip. Plain and Redistribution should both start ticked. It would be nice if there was an indicator of some kind that differentiated which of the two kinds of transfers that part met." | A13 confirmed, plus a **franchise filter**. **A12 changed:** both kinds start ticked, with a **kind badge** on each line. |
| 6 | **Wording.** "Excess" means stock available to transfer. Round 1's Excess is renamed "Above target". | "Excess is months of supply over the set threshold has defined in item 1. I would like to stick with the "Excess" word so that it stays consistent with John Deere naming." | A16 confirmed: "Excess" has the transfer meaning. Round 1's on-hand-above-target figure keeps the "Above target" label. Excess is shown in months as well as units. |
| 7 | **Phase-in.** A quantity and an end date (default 12 months); it ends early once the rules stock the part. | "Correct" | A18 confirmed. |
