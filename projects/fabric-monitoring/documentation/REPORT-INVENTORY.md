## How to Complete This Inventory

### Automated Fields
The following are populated automatically:
- Report Name
- Workspace Published
- Dataset Name
- Update Schedule
- Last Updated

### Manual Entry Required
Open the CSV file to add:
1. **DataflowsUsed** - List of dataflow names (comma-separated)
2. **TablesUsed** - List of table names (comma-separated)
3. **MigrationStatus** - Options:
   - Old Structure - Uses LH - *_Data_Prep workspaces
   - New Structure - Uses LH_Master_Data
   - Migrated - Recently moved to new structure
   - In Progress - Currently being migrated
4. **Notes** - Any additional information

### Finding Dataflows and Tables
For each report:
1. Open the report in Power BI Desktop
2. Go to **Transform Data** > **Data Source Settings**
3. Note the Lakehouse and tables being used
4. Check the lakehouse workspace for matching dataflow names
5. Update the CSV file with this information
